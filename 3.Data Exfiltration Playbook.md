# 3. Data Exfiltration Playbook

## 📌 Overview
This playbook guides SOC Analysts through detecting, isolating, and containing unauthorized data exfiltration over various protocols (HTTPS, DNS tunneling, FTP, cloud storage, external storage media).

---

## ⚙️ PHASE 1: Preparation
* **Baseline Activity:** Maintain bandwidth and protocol baselines for network usage across departments.
* **DLP Deployment:** Configure Data Loss Prevention (DLP) rules and cloud access security broker (CASB) monitoring for sensitive data types (PII, PCI, source code).

---

## 🔎 PHASE 2: Detection & Analysis
1. **Identify Anomalies:**
   * Detect abnormal outbound network volume spike from an endpoint or database server.
   * Spot large file uploads to personal cloud drives (e.g., Mega, Google Drive, WeTransfer) or raw IPs.
2. **Protocol Analysis:**
   * Check for high-frequency DNS requests with long encoded subdomains (DNS Tunneling).
   * Review proxy logs for unusual outbound encrypted connections.
3. **Scope the Data:**
   * Determine what files/data stores were accessed, staged (e.g., `7z`, `rar`, `tar` archives created in temp directories), or transmitted.

---

## 🛡️ PHASE 3: Containment
1. **Network Isolation:** Immediately isolate affected host(s) via EDR to sever established egress streams.
2. **Block Destination Destinations:** Block target remote IP addresses and external storage domains at the proxy/firewall level.
3. **Revoke Access:** Disable compromised user credentials and API tokens associated with the file movement.
4. **Kill Processes:** Terminate staging or transfer utilities (e.g., `rclone.exe`, `7zip`, `curl`, custom scripts).

---

## 🧹 PHASE 4: Eradication & Recovery
1. **Malware & Artifact Removal:** Remove staging archives, exfiltration scripts, and secondary persistence tools.
2. **Credential Rotation:** Rotate all service account keys and enterprise secrets if key storage locations were accessed.
3. **System Audit:** Validate that host configuration and file permissions are re-secured before restoring network access.

---

## 📝 PHASE 5: Post-Incident Activity
1. **Regulatory Reporting:** Notify Legal, Data Privacy Officer (DPO), and compliance teams if sensitive data (PII/PHI) was exfiltrated.
2. **Policy Enhancement:** Update DLP rules to block specific file types, archival utilities, or unapproved cloud storage providers.
3. **Lessons Learned Report:** Draft a complete post-incident report detailing exfiltrated volume, timeline, root cause, and remediation steps.
