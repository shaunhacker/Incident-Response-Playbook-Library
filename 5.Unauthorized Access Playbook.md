# 5. Unauthorized Access Playbook

## 📌 Overview
This playbook covers procedures for handling unauthorized access, compromise of privileged accounts, session hijacking, or suspicious lateral movement within the enterprise environment.

---

## ⚙️ PHASE 1: Preparation
* **Privileged Access Management (PAM):** Enforce Least Privilege, PAM solutions, and Just-In-Time (JIT) administrative access.
* **Logging:** Centralize authentication logs from domain controllers, cloud tenants, and critical servers into the SIEM.

---

## 🔎 PHASE 2: Detection & Analysis
1. **Anomaly Detection:**
   * Detect impossible travel alerts, logins from unusual geographical locations, or abnormal access times.
   * Identify unauthorized privilege escalation (e.g., user added to Domain Admins or Global Admin roles).
2. **Lateral Movement Tracking:**
   * Check logs for suspicious tool usage (`PsExec`, `WMI`, `WinRM`, `RDP`) across internal systems.
3. **Session Audit:**
   * Audit current user sessions, token impersonation, or Kerberos ticket anomalies (e.g., Pass-the-Hash, Pass-the-Ticket).

---

## 🛡️ PHASE 3: Containment
1. **Account Disablement:** Instantly disable the affected compromised account(s).
2. **Session Termination:** Revoke all active OAuth sessions, refresh tokens, and global user logins.
3. **Isolate Affected Systems:** Isolate host machines where lateral movement or administrative tools were used without authorization.

---

## 🧹 PHASE 4: Eradication & Recovery
1. **Privilege Audit:** Revert unauthorized group membership or permission changes back to baseline configuration.
2. **Password & Key Reset:** Force password resets and rotate associated service keys/tokens.
3. **Vulnerability Remediation:** Patch local privilege escalation (LPE) vulnerabilities exploited during the intrusion.
4. **Account Restoration:** Restore normal account privileges after thorough identity verification.

---

## 📝 PHASE 5: Post-Incident Activity
1. **Access Review:** Conduct a comprehensive audit of privileged access across the organization.
2. **Detection Optimization:** Build/tune SIEM logic targeting unauthorized administrative group modifications and abnormal lateral movement patterns.
