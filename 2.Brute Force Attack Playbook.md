# 2. Brute Force Attack Playbook

## 📌 Overview
This playbook provides systematic steps for identifying, containing, and mitigating automated login attacks, password spraying, and dictionary attacks against enterprise authentication systems (RDP, SSH, VPN, Entra ID/Active Directory).

---

## ⚙️ PHASE 1: Preparation
* **Logging Setup:** Ensure audit policies log successful and failed authentication events (Windows Event ID 4625 for failed logins, Event ID 4624 for successful logins).
* **Policy Thresholds:** Enforce Account Lockout Policies (e.g., lock after 5 failed attempts within 15 minutes) and mandatory Multi-Factor Authentication (MFA).

---

## 🔎 PHASE 2: Detection & Analysis
1. **Alert Validation:**
   * Correlate burst failed login events within a short timeframe originating from a single IP or user.
   * Differentiate between **Brute Force** (many attempts on 1 account) and **Password Spraying** (few attempts across many accounts).
2. **Log Querying:**
   ```kql
   // Azure Sentinel: Detecting high failure volume followed by success
   SecurityEvent
   | where EventID == 4625
   | summarize FailedCount = count() by Account, IpAddress, bin(TimeGenerated, 10m)
   | where FailedCount > 20
